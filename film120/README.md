# FROM MELTING PIXELS TO MOVING WORLDS

A 120.000 s, 1080x1920, 30 fps vertical film (final MP4: see `docs/QA_AND_LIMITS.md` for the link and QA) about the evolution of generative AI video (2016 experiments to the strongest developer-announced systems at the production date, 2026-09-29).
Everything in this folder is the **editable project**: the film is generated by code from a footage shortlist, an edit plan, the narration script and a cue sheet - change any of them and re-render.

## Layout

| Path | What |
|---|---|
| `data/script.json`, `data/vo/` | narration (ElevenLabs v4 takes, word-aligned `vo.json`, final wavs) |
| `data/research/R1-R6.json`, `docs/RESEARCH_SOURCES.md` | verified research pool: every claim has a source URL + verbatim quote; 319 distinct pages indexed |
| `data/candidates/`, `data/verified/`, `data/shortlist.json` | footage hunt, adversarial licence/version verification (strictest verdict wins), the 29 excerpts / 28 clips actually used |
| `tools/author_shortlist.py` | the authored edit: which excerpt plays where, all on-screen plates and captions (the CAST) |
| `data/cue_spec.json`, `tools/make_cues.py` | narration-anchored cue times (word-level) that drive sequence timing |
| `engine/`, `seq/seq01..seq14_*.py` | the motion-design engine (numpy/Pillow compositor) and the 14 bespoke sequences |
| `audio/`, `data/audio/` | procedural score + SFX, licensed SFX/music catalogue (measured, unlistened), mixer |
| `tools/sandbox_run.sh` | every pipeline stage (`setup fonts vo media plan preview render audio final`) - re-runnable from this repo |
| `tools/qa_video.py`, `docs/QA_AND_LIMITS.md` | numeric QA of the finished file + honest list of what was not checked |
| `CREDITS.md`, `FOOTAGE_SOURCES.md`, `footage_sources.csv` | footage + audio credit list |

## Rebuild

```
W=~/film2 SHA=<commit> tools/sandbox_run.sh setup && ... fonts && ... vo && ... media && ... plan
tools/sandbox_run.sh render 0 40 0; render 40 80 20; render 80 120 40    # ~2.5 min per 40 s on 8 cores
python3 tools/audio_layers.py fetch $W/lic; tools/sandbox_run.sh audio; tools/sandbox_run.sh final
python3 tools/qa_video.py $W/film.mp4
```

Needs ffmpeg, numpy, Pillow, scipy, faster-whisper (word alignment) and internet (footage + licensed audio are fetched, never committed).

## Honesty rules used in the edit

* Footage is only used as evidence of the model that made it; unreleased/closed models are shown as dated data cards, never with stand-in footage.
* Every clip carries its source label (model, year, creator, licence); watermarks/credits inside sources are preserved (a source is letterboxed rather than cropped when a mark would be cut).
* Upscaled or low-resolution sources are shown at their native pixels and never called native 1080p.
* Side-by-side comparisons are labelled ILLUSTRATIVE unless both clips share one prompt; there are no scores, percentages or rankings anywhere.
* The capability matrix shows only "documented by the developer, first in year X"; an empty cell means "not verified in our research", not "absent".
* The camera-control diagrams are overlays on unrelated footage and say so on screen.
